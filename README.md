# Lab 6: Quizzler

## Mô tả

Quizzler là ứng dụng câu hỏi đúng/sai được tách dữ liệu và logic khỏi giao diện. Sau câu cuối, ứng dụng thông báo hoàn thành rồi đặt lại bài quiz.

## Chức năng

- Hiển thị lần lượt các câu hỏi
- Kiểm tra câu trả lời Đúng hoặc Sai
- Ghi kết quả bằng biểu tượng check/close
- Thông báo hoàn thành và reset

## Công nghệ

- Flutter
- Dart

## Cách chạy

```bash
flutter pub get
flutter run
```
